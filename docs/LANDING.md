# Precision Landing (Phases 15–18)

## Target detection (`landing_detector`)
Downward camera → OpenCV ArUco detector with the **AprilTag 36h11** dictionary (id 0, 0.40 m tag on a 0.60 m white
plate, generated by `scripts/generate_world.py`) → sub-pixel corners → `solvePnP(IPPE_SQUARE)` → tag centre in
`down_camera_optical_frame` → TF2 at the image stamp → map frame → exponential filter (α = 0.5, reset on > 1 m jump)
→ `/landing/target_pose`. The marker is only a precision aid: the vehicle first navigates to the *approximate*
landing zone (41, 41) from `configs/mission.yaml`, 1.4 m from the true pad (42, 42).

## LiDAR validation (`landing_validator`)
Downward flash LiDAR → map frame → around the target:
* ground plane: ≥ 30 returns in a 1.2 m disc; least-squares plane with iterative inlier selection on the lowest layer
* tilt ≤ 8°, plane RMS ≤ 5 cm
* clearance: < 3 returns more than 0.15 m above the plane within 2.0 m
* height above ground (vehicle z − plane z)
* alignment: horizontal target-vehicle offset ≤ 0.35 m
A detected marker alone **never** triggers descent: `ALIGN → DESCEND` requires a fresh `surface_ok`.

## State machine (`landing_controller/state_machine.py`)
```
NAVIGATE → LANDING_ZONE_SEARCH → TARGET_LOCK → ALIGN → DESCEND → FINAL_CHECK → LAND → LANDED
TARGET_LOST  → hover → reacquire (→ ALIGN) | timeout 10 s → ABORT_CLIMB → LANDING_ZONE_SEARCH
UNSAFE_PAD   → ABORT_CLIMB (to 5 m) → LANDING_ZONE_SEARCH   (max 3 attempts → ABORTED)
SENSOR_FAILURE (watchdog) → hover → resume | 10 s → ABORTED
```
* Search: square pattern ±3 m around the zone at 5 m, two loops max.
* Lock: ≥ 10 fresh detections (~0.5 s).
* Align: PID on map-frame target error (Kp 0.8, Ki 0.05, Kd 0.15, |v| ≤ 0.6 m/s, integral clamp 0.5, conditional
  integration anti-windup, filtered derivative); altitude held; aligned < 0.15 m for 1 s.
* Descend: 0.4 m/s (0.25 m/s below 1.2 m AGL), descent paused when error > 0.30 m.
  **Re-validation checkpoints at 2.0, 1.0 and 0.5 m AGL** (fresh LiDAR verdict + alignment required, 5 s timeout ⇒ abort).
* Final check at 0.45 m AGL (feet ≈ 0.23 m above the pad): error ≤ 0.225 m ⇒ PX4 `NAV_LAND`; land detector ⇒ LANDED, disarm.

## Landing error
`E = √((Px − Tx)² + (Py − Ty)²)` with P = ground-truth touchdown position (evaluation only) and T = pad centre from the
world spec. Reported per run and aggregated (mean, median, RMSE, P95) in `results/summary.json`.
